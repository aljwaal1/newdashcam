# داش كام بدون صوت

تطبيق Flutter Android لتسجيل الفيديو بدون صوت.

الميزات:
- تسجيل فيديو فقط بدون ميكروفون.
- اختيار الكاميرا الأمامية أو الخلفية.
- وقت وسرعة بخط صغير مثل أجهزة الداش كام.
- حفظ التسجيلات وتشغيلها ومشاركتها وحذفها.
- GitHub Actions يبني APK باسم: `DashCam-No-Audio.apk`.

مهم: ارفع كل محتويات هذا المجلد، بما فيها مجلد `lib` ومجلد `.github`.
